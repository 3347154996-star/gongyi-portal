# 工艺部业务门户

蓝白配色的本地业务工作台，包含独立管理员登录页及四个入口：补焊周报、补焊实时监控、安灯报警、定位销与伸缩气缸管理。门户管理员与公司数据连接使用两套独立登录。

## 本地运行

前提：电脑安装 Node.js 22 或更新版本，且能访问业务系统网络。

1. 将 `config.example.json` 复制为 `config.local.json`，由系统维护人员填写 API 地址、网页地址、登录参数和前后副物料组。公开版本只提供占位配置。
2. 在项目目录运行 `npm run setup`，设置本机管理员账号和密码。密码输入不显示，仅保存加盐摘要；公开源码没有默认账号密码。
3. 运行 `npm start`，或者在 Windows 双击 `启动门户.cmd`。
4. 浏览器打开控制台显示的本机地址，用本机管理员登录，即可进入四个功能；CSV 清单校验不要求公司连接。
5. 点击“连接公司数据”，输入有权限的公司业务系统账号。成功连接后才能读取真实数据。公司登录失败不会影响门户管理员登录。
6. 使用结束后，退出门户并关闭启动窗口。重启服务后需重新登录。

这是本地运行服务，不能通过双击 `public/index.html` 完成数据连接，也没有部署到互联网。无需安装第三方运行依赖。

## 功能与口径

- **补焊周报**：前副/后副分组；焊偏、焊穿每条源记录计 1 点，重复记录保留；件数按同组同时间范围内非空二维码去重。展示点数、涉及件数、点/件、位置 Top 5、产线分布、各线 OP 占比和已读取区间的五周趋势。日期区间是统计依据，未把企业 KW 编号硬套为 ISO 周。
- **补焊实时监控**：当天累计和最新记录，默认每 30 秒刷新，可暂停或改为 15/60 秒；页面隐藏时暂停。属于定时读取，不是服务器事件推送。点数来自不合格日志，不能据此确认完成补焊。
- **安灯报警**：按日期与关键词读取报警记录。报警记录不等于设备即时运行状态。
- **定位销与伸缩气缸管理**：读取模具备件台账库存快照，按名称和类别筛选重点备件；库存不按录入日期过滤。
- **入库清单本地校验**：支持 CSV UTF-8，校验必填项、正整数数量、重复、类型和公式风险，输出预览与准备文件。当前不支持 XLS/XLSX，不写入生产库存。原系统台账导入与入库流水是两个接口，尚未核验当前账号的正式入库权限。

局限性：真实连接依赖有效账号、相应模块权限和网络可达性。代码的模拟测试不能替代公司环境联调。源系统没有提供稳定分页快照，取数期间记录变动可能影响统计；数量变化、日期异常、分页上限会明确标记部分数据。缺少历史数据时显示缺失，不填零、不生成不具备可比性的环比。当前最大查询区间为 42 天，默认每次最多读取 50 页（每页 200 条），建议从较短区间开始。

## 本地文件与公开源码

`config.local.json` 仅留在使用者电脑，不加入版本控制。管理员密码仅存随机盐与 scrypt 摘要；公司密码只用于本次连接，不落盘。业务会话保存在服务内存，浏览器仅保留本机 HttpOnly 会话标识。服务只监听回环地址；拒绝跨站请求，业务查询仅允许已核验的三个读取接口。退出或重启会清除本地会话。公司会话失效仅要求重连公司数据，门户管理员保持登录。

公开仓库不包含公司地址、账号密码、真实业务记录、原网站下载的源代码样本或本地接口核对资料。品牌图仅用于本项目界面展示；仓库公开不授予品牌商标的使用许可。

## 开发与验证

```sh
npm test
npm run setup
npm start
```

前端为 `public/` 下的原生 HTML/CSS/JavaScript；`server.cjs` 提供本机登录和读取服务；`lib/source.cjs` 适配业务系统协议；`lib/weld-report.cjs` 执行纯统计；`lib/import-preview.cjs` 仅校验清单。测试全部使用人工构造的记录和模拟业务系统，不会调用公司系统或修改生产数据。

后续开放正式入库前，需要核对备件主键、入库字段、权限和防重复提交规则，并以用户确认的具体清单进行提交。
