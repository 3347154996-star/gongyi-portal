使用说明与解析规则

一、怎么用

  1. 点「选择文件夹」导入机器人备份（含 RAPID 的整个备份文件夹即可）。
  2. 工具自动按 TASK 分组，默认只检索「正在使用」的焊接程序（主程序启用、未被 ! 备注），列出其焊接段参数；勾选「显示全部」可查看被注释/未引用的程序。
  3. 用「筛选」按 任务 / 关键词 / 主程序状态 缩小范围（可选）。
  4. 点「导出 Excel / CSV」或「复制到剪贴板」取得结果（导出内容＝当前视图）。

二、解析规则

  • 焊接过程：文件里含活动 ArcLStart 的 PROC…ENDPROC 段；以 ! 开头的行是注释，不算。
  • 焊接段：一条 ArcLStart 到对应的 ArcLEnd/ArcCEnd。
  • 焊缝号(备注)：段前（跨过准备动作与被注释代码）遇到的第一条 !注释；没有则显示“未标注”。
  • 任务：按路径里的 TASK数字 分组；变位机等无焊接指令的任务自动忽略。
  • 主程序状态：读 MainModule.mod——行首无 ! 的 WL_…; 为“调用(启用)”；有 ! 为“注释”；未出现为“未引用”。

三、welddata 参数换算

TASK PERS welddata 名称:=[速度, 0, [焊接模式, ?, 电压, 电流, …], …];
· 速度(IPM) = [0] × 2.362203794　　· 电压(V) = [2][2]（直接用）　　· 电流(A) = [2][3] × 2.362204724
· 参数来源优先取同一任务内声明该 welddata 的文件；跨任务同名(如 weld1)按任务隔离。
