视觉检具采集工具 v2 · Windows 64 位免安装版

1. 如果旧工具正在采集，先按 Ctrl+C，返回菜单后输入 0 退出。
2. 把压缩包中的“视觉采集工具.exe”和本说明解压到 E:\CEN\采集，替换同名程序。保留已有 data 文件夹。
3. 双击“视觉采集工具.exe”，确认标题显示 v2。
4. 首次选择 1（近期采集一次），等结果显示后截屏核对。
5. 试采集确认正常后，再选择 2（持续采集）。保持窗口开启。

这份程序已经包含所需 Python 运行环境，不需要在检具电脑安装 Python。
适用于 Windows 10 / 11 的 64 位电脑，不需要管理员方式启动。
压缩包要先解压；不要从压缩软件内直接运行程序。

固定读取位置：D:\BaseV3\ReleaseEXE\backup
只读取：Tesla_Front11 和 Tesla_Front12 的普通检测日期文件夹。
排除：ALLmeasure 全检和 failure。
默认扫描并导出今天及昨天，避免首次整库扫描，也覆盖跨午夜刚完成的检测。
按检具电脑的本地日期判断；持续采集跨日后自动更新日期范围。
更早历史保留在已有数据库中，不会删除，但本次 JSON 不包含那些记录。
数据库原有大小不会因此自动缩小；是否成功应看进度、统计结果和 vision.json。
第一次用新版打开旧数据库时会建立日期索引，避免以后每轮读取整库。

输出在 EXE 所在文件夹的 data 中：
- vision.sqlite：采集工具自己的数据库，用于保留记录及去重。
- vision.json：后续提供给网页读取的数据。

不要删除或单独替换 vision.sqlite；vision.sqlite-journal 也不要手动删除，交由数据库处理。
更新 EXE 时保留已有 data 文件夹。程序按文件保存进度，中断后已经提交的数据仍保留。
同一设备标识固定为 vision-01；其他设备接入时需另设标识，避免混淆。
工具不修改源 CSV、检具数据库或检具配置，也不自动创建网络共享。

结果说明：
- imported：本次新增检测记录。
- duplicates：已采集过的记录，不重复计数。
- conflicts：同一次检测存在不同内容，需要核对。
- deferred：文件仍在变化，下一轮再读。
- errors：读取错误列表。正常应为 []。

如果 imported 和 duplicates 都是 0，需要确认电脑日期正确、对应今天/昨天目录存在普通检测文件。
如果出现 errors，不要据此认定已经采集完整；把窗口截图发来核对。
持续采集时按 Ctrl+C 停止；如果显示菜单，选择 0 退出。
同一个采集目录一次只开一个采集窗口。

本机试运行通过不代表现场已经连通。网页自动同步仍需配置检具共享路径及读取权限。
默认近期范围不代表全部历史已经接入；补历史时需单独安排日期范围及容量。
网页目前最多接收 20,000 条 / 128 MB 的本地数据；超过时会保留旧数据并报错，需要先安排归档或扩展存储。
