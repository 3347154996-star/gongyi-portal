# 公司尺寸接口接入

“视觉检具 → 公司系统”由门户服务器读取 MES 中已上传的检测记录，提供线体筛选、合格率趋势及测点详情。现场检具已经向这套 MES 上传数据时，门户不需要再逐台读取检具共享文件夹。

## 部署前提

- 运行门户服务的电脑或厂内服务器能够访问公司 MES。查看网页的其他电脑只需能访问门户服务器。
- 管理员拥有可读取线体目录、工序报表和参数详情的公司账号；账号能登录不等于具有全部线体的数据权限。
- 对应检具已将完整检测结果上传到 MES，包括 OK、NG、检测时间、工件码、设备及工序。首次使用其他线体时，应抽查现场检测与 MES 报表是否对应。

沿用门户已有的 `config.local.json` 公司数据源地址和登录配置，不另外建立检具账号清单。地址应由公司维护人员提供；文档中的示例域名 `https://mes.example.invalid` 仅为占位，不能用于真实连接。

管理员登录门户，打开“数据源设置”，填写获授权的公司账号并点击“验证并保存设置”。如果现有公司数据源已连接成功，可直接使用。本模块复用门户保存的加密凭据和公司会话，密码、公司令牌不发送给浏览器。

Windows 本机保存的凭据受当前 Windows 用户保护。迁移到厂内服务器或换用其他 Windows 用户运行时，应在新环境重新验证并保存数据源；复制程序目录不等于迁移了可用的登录状态。非 Windows 环境沿用门户支持的环境变量凭据方式，不回退为明文密码文件。运行环境和访问部署步骤见 [门户说明](../README.md)及[手机访问与部署](手机访问与部署.md)。

## 使用方法

1. 打开“视觉检具”，将“检测数据来源”选为“公司系统”。
2. 选择检测线体、开始和结束时间。快捷按钮提供今天、近 7 天、近 30 天。
3. “查看数量”可选最近 100、500、1000 次或日期内全部。最近数量仍受当前时间范围限制，并不是跨全部历史寻找最近记录。
4. 点击“查询记录”。如需查某个工件，可填写或扫描工件码；这种筛选不显示整线合格率。
5. 在检测记录中打开“测点详情”，查看这一次检测的实测值、上下限和原始判定，可勾选“只看 NG”。

时间按北京时间处理；结束时间精确到分钟时包含该分钟，实际查询终点不晚于本轮查询开始时刻。页面可见且没有打开详情时，每轮完成后间隔 60 秒发起刷新，也可点击“刷新数据”。这是定时查询，不是检具或 MES 主动推送；关闭页面不会继续轮询此报表。

## 线体目录与本地配置

目录从当前账号可读取的公司线体列表动态发现，筛选名称中包含“尺寸”“视觉”或“光学”、且具有“代码-名称”格式的项目。没有写死公司名称或实际线体编号。目录中出现某条线体，只说明该账号可见该目录项，不证明现场上传完整。

可在本机 `config.local.json` 的既有 `vision` 对象内合并以下配置，不要覆盖其他配置项：

```json
{
  "vision": {
    "mes": {
      "defaultLineId": "",
      "maxPages": 150
    }
  }
}
```

`defaultLineId` 留空时选目录中的第一条；指定时填写当前目录返回的线体 ID，而非线体名称。指定 ID 不在当前账号目录中时，仍回到第一条。`maxPages` 为本模块最多读取页数，每页 200 条，最多允许 150 页；它独立于其他报表的分页设置。一次查询的读取时间上限为 45 秒。配置变更后需重新启动门户服务才能生效。

线体未出现时，先核对账号权限、MES 目录命名和上传配置。不要仅靠新增门户台账条目认定已经接通；当前自动发现也不覆盖所有可能的公司命名方式。

## 统计口径与读取保护

- 每个工序报表记录 ID 表示一次检测。同一工件码的多次复测分别保留；不把它们合并为工件的最终结论，也不称为“一次通过率”。
- 合格率采用工序报表的原始 OK/NG，按 `OK 次数 ÷ (OK 次数 + NG 次数)` 计算。测点 NG 数不能代替工件判定。
- 返回记录必须属于所选线体和时间范围，且是同一个明确的尺寸、视觉或光学工序。混有多个工序、工序不明或未知判定时保留可读记录，但不展示合格率。
- 来源总数变化、重复 ID、排序异常、分页未读完、超时或复核失败时，页面明确显示范围不完整，不用已读部分冒充完整合格率。可缩短时间范围或改为最近若干次后重新查询。
- 详情中的无名称采集状态字段不计入测点数量，页面说明排除数量。来源未提供测点单位时，不自动标成毫米或解释为尺寸偏差。

只调用已核实的读取接口：线体目录 `/api/Cx/select`、检测列表 `/api/ProcessReport`、按已读记录 ID 获取详情 `/api/ProcessReport/detail/{id}`。此接入不提交不合格、返工、质量确认或外部推送操作。详情只能查询当前公司会话已读取的记录；服务重启、会话变化或缓存过期后，先重新查询列表。

## 局限性与其他来源

MES 尚未收到或尚未开放读取的数据，本门户无法显示；没有新增记录也不直接等于检具断线。页面刷新时间表示取数时间，不代表检具上传时间，不能据此保证现场数据零延迟。

来源没有提供分页快照标识。本模块冻结查询结束时间、检查总数和排序，并在完成时复核第一页，但仍不能完全排除读取期间其他页的旧记录被原地修改。正式验收应按同一线体、时间及复测口径与 MES 对账；新增线体需分别核对。

“采集文件”仍是另一个数据来源，使用原有本地或共享文件接入方式，操作见 [视觉检具接入](视觉检具接入.md)。两种来源分别查询和统计，不合并计数，也不自动互相补缺，避免同一次检测被重复计算。

已核实的 MES 报表字段未提供 `ALLmeasure`／全检标识。当前公司系统查询不能执行与 CSV 文件夹“排除全检”相同的筛选，也不能声称 MES 数据已经排除全检。若现场需要严格保持这一口径，应由 MES 维护人员确认上传范围或提供可用的检测类型字段，再核对两种来源的统计差异。

折叠区“历史不合格参数查询”用于核查历史 NG。它可能返回某次历史不合格数据，不能代替最新检测记录，不能作为全线合格率的分母；判断复测变化应查看公司工序报表中各次检测时间及结果。

公开代码及本文不包含公司真实地址、账号、密码、工件码或业务数据；本机配置和现场核对资料继续按内部资料管理。
