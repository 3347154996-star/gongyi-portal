# 公司尺寸接口接入

“视觉检具”统一由门户服务器读取公司 MES 中已上传的检测记录，提供线体、物料、检具筛选、合格率趋势及测点详情。现场检具已经向这套 MES 上传数据时，门户不需要再逐台读取检具共享文件夹。

## 部署前提

- 运行门户服务的电脑或厂内服务器能够访问公司 MES。查看网页的其他电脑只需能访问门户服务器。
- 管理员拥有可读取线体目录、工序报表和参数详情的公司账号；账号能登录不等于具有全部线体的数据权限。
- 对应检具已将完整检测结果上传到 MES，包括 OK、NG、检测时间、工件码、设备及工序。首次使用其他线体时，应抽查现场检测与 MES 报表是否对应。

沿用门户已有的 `config.local.json` 公司数据源地址和登录配置，不另外建立检具账号清单。地址应由公司维护人员提供；文档中的示例域名 `https://mes.example.invalid` 仅为占位，不能用于真实连接。

管理员登录门户，打开“数据源设置”，填写获授权的公司账号并点击“验证并保存设置”。如果现有公司数据源已连接成功，可直接使用。本模块复用门户保存的加密凭据和公司会话，密码、公司令牌不发送给浏览器。

Windows 本机保存的凭据受当前 Windows 用户保护。迁移到厂内服务器或换用其他 Windows 用户运行时，应在新环境重新验证并保存数据源；复制程序目录不等于迁移了可用的登录状态。非 Windows 环境沿用门户支持的环境变量凭据方式，不回退为明文密码文件。运行环境和访问部署步骤见 [门户说明](../README.md)及[手机访问与部署](手机访问与部署.md)。

## 使用方法

1. 打开“视觉检具”，直接使用公司系统的检测记录。
2. 选择检测线体，再选择“按时间”或“按数量”，两者互斥。“按时间”读取所选起止时间内符合条件的全部记录，支持小时、分钟；不再同时限制最近数量。“按数量”填写最近 1–20000 次检测，不应用页面的起止日期。
3. 按需选择物料、检具和检测结论。物料可细分为同一物料的 11 线、12 线等，无法识别 SN 线号的记录单列“待确认”。物料与检具按编号、SN 线号按解析后的编号精确匹配；选项仅来自本次已读取的记录，并非全公司物料或设备目录。切换更宽的时间范围或数量，才可能读到较早记录中的其他选项。
4. 数量模式先应用物料、SN 线号、检具和结论筛选，再取匹配条件下最近的检测，可跨日期查询。它从本模块支持的历史下界 `2000-01-01 00:00:00` 查到本轮查询开始时刻，受公司当前开放的历史记录范围和读取上限约束；不是不受限制的历史归档搜索。页面显示实际选中记录的最早、最晚检测时间。少于指定数量时，必须确认来源已经读完才标记完整，不能仅因今天记录较少就停止。
5. 点击“查询记录”。如需查某个工件，可填写或扫描完整工件码，按精确工件码查询。单工件查询或只查看 OK／NG 时不显示线体合格率。
6. 在检测记录中打开“测点详情”，查看这一次检测的实测值、上下限和原始判定，可勾选“只看 NG”。
7. 数据完整且非空、筛选已应用后，点击“一键报告”预览当前条件下的单页报告。报告与统计使用同一批公司检测记录；未应用的新筛选、不完整结果或空结果不能生成报告。单工件或单一结论筛选的报告仍保留相应口径说明，不补造线体合格率。

时间按北京时间处理；时间模式的结束时间精确到分钟时包含该分钟，实际查询终点不晚于本轮查询开始时刻。数量模式的历史搜索边界与实际样本时段是不同概念：搜索范围不说明这些年份都有记录，实际样本时段只覆盖本次选中的检测。页面可见且没有打开详情或报告预览时，每轮完成后间隔 60 秒发起刷新，也可点击“刷新数据”。这是定时查询，不是检具或 MES 主动推送；关闭页面不会继续轮询此报表。

## 线体目录与本地配置

目录从当前账号可读取的公司线体列表动态发现，筛选名称中包含“尺寸”“视觉”或“光学”、且具有“代码-名称”格式的项目。可用目录不依赖预先写死的实际线体编号。目录中出现某条线体，只说明该账号可见该目录项，不证明现场上传完整。

按现场要求，门户目录另精确排除 `TSL四期前副在线尺寸检测`、`TSL四期后副在线尺寸检测` 以及名称中“副”写作“幅”的两个对应项；其他四期项目和七期等检测线仍按正常规则显示。此规则只影响本门户可选、可查询的目录，不删除或修改公司系统数据。原默认 ID 被排除后，会回到当前有效目录的第一项。

可在本机 `config.local.json` 的既有 `vision` 对象内合并以下配置，不要覆盖其他配置项：

```json
{
  "vision": {
    "mes": {
      "defaultLineId": "",
      "maxPages": 150
    }
  }
}
```

`defaultLineId` 留空时选目录中的第一条；指定时填写当前目录返回的线体 ID，而非线体名称。指定 ID 不在当前账号目录中时，仍回到第一条。`maxPages` 为本模块最多读取页数，每页 200 条，最多允许 150 页；它独立于其他报表的分页设置。一次查询的读取时间上限为 45 秒。配置变更后需重新启动门户服务才能生效。

线体未出现时，先核对账号权限、MES 目录命名和上传配置。不要仅靠新增门户台账条目认定已经接通；当前自动发现也不覆盖所有可能的公司命名方式。

## 统计口径与读取保护

- 每个工序报表记录 ID 表示一次检测。同一工件码的多次复测分别保留；不把它们合并为工件的最终结论，也不称为“一次通过率”。
- “检测线体”来自 MES 的检测工序目录；物料细分的“生产线号”来自 SN 尾段，两者不是同一字段。已确认的 SN 规则为末尾 `两位数字 + A/B + 数字序号`，只取 A/B 紧邻前面的两位数字；11A、11B 都归 11 线，12A、12B 都归 12 线，其他两位数字同理。A/B 不区分大小写，01 归 1 线；00、其他字母、缺少末尾序号或不符合该尾段规则的记录归“待确认”。不从 SN 中间的类似片段、物料名称或 MES 线体名称猜测线号，也不把前面的日期数字并入线号。
- 合格率采用工序报表的原始 OK/NG，按 `OK 次数 ÷ (OK 次数 + NG 次数)` 计算。测点 NG 数不能代替工件判定。
- 物料、SN 线号、检具筛选后的完整样本可计算该范围的合格率；只查看 OK、只查看 NG 或限定单个工件时，仅展示检测次数与记录，不把选择后的 100%／0% 当作线体合格率。读取完成与能否计算合格率是两个独立条件。SN 线号待确认不改变原始 OK/NG，待确认样本可单独查看。
- 物料、SN 线号、检具和结论条件在门户服务器上对已验证的公司接口记录进行筛选，没有向公司接口附加未核实的过滤参数。为找到指定数量的匹配记录，可能需要读取多页；达到读取上限但未找到足够记录时仍标为不完整。
- 返回记录必须属于所选线体和时间范围，且是同一个明确的尺寸、视觉或光学工序。混有多个工序、工序不明或未知判定时保留可读记录，但不展示合格率。
- 来源总数变化、重复 ID、排序异常、分页未读完、超时或复核失败时，页面明确显示范围不完整，不用已读部分冒充完整合格率。可缩短时间范围或改为最近若干次后重新查询。
- 详情中的无名称采集状态字段不计入测点数量，页面说明排除数量。来源未提供测点单位时，不自动标成毫米或解释为尺寸偏差。

只调用已核实的读取接口：线体目录 `/api/Cx/select`、检测列表 `/api/ProcessReport`、按已读记录 ID 获取详情 `/api/ProcessReport/detail/{id}`。此接入不提交不合格、返工、质量确认或外部推送操作。详情只能查询当前公司会话已读取的记录；服务重启、会话变化或缓存过期后，先重新查询列表。

本地查询接口使用 `queryMode: "time" | "count"`。时间模式强制 `limit: 0`；数量模式要求 `limit: 1..20000`，忽略客户端起止日期。旧调用方未传 `queryMode` 时暂保留原“日期加最近数量”的组合行为。`filters` 返回实际查询模式、有效搜索范围和 `productionLine` 条件；`coverage.firstMeasuredAt`／`lastMeasuredAt` 返回选中记录的实际时段，空结果为 `null`。`coverage.sourceExhausted` 表示分页已抵达来源总数，只有同时通过完整性检查才能认定少于指定数量的结果可信。

## 局限性与历史文件

MES 尚未收到或尚未开放读取的数据，本门户无法显示；没有新增记录也不直接等于检具断线。页面刷新时间表示取数时间，不代表检具上传时间，不能据此保证现场数据零延迟。

来源没有提供分页快照标识。本模块冻结查询结束时间、检查总数和排序，并在完成时复核第一页，但仍不能完全排除读取期间其他页的旧记录被原地修改。正式验收应按同一线体、时间及复测口径与 MES 对账；新增线体需分别核对。

视觉检具页面已经统一使用公司接口，不再读取采集 JSON、SQLite 或共享文件，也不再自动轮询原采集路径。已有历史文件保留在原位置，本次切换不删除、不导入，也不与公司记录混算；旧采集说明仅作为历史维护资料。

已核实的 MES 报表字段未提供 `ALLmeasure`／全检标识。当前公司系统查询不能执行与原 CSV 文件夹“排除全检”相同的筛选，也不能声称 MES 数据已经排除全检。若现场需要严格保持这一口径，应由 MES 维护人员确认上传范围或提供可用的检测类型字段，再核对与历史采集口径的差异。

折叠区“历史不合格参数查询”用于核查历史 NG。它可能返回某次历史不合格数据，不能代替最新检测记录，不能作为全线合格率的分母；判断复测变化应查看公司工序报表中各次检测时间及结果。

公开代码及本文不包含公司真实地址、账号、密码、工件码或业务数据；本机配置和现场核对资料继续按内部资料管理。

## 公司尺寸单页报告

另有“加载全部测点”入口，用于当前已应用筛选范围的 NG 帕累托、测点排行、整件结果构成及测点实际值趋势。它与下面的检测汇总单页报告分别提供导出：测点报告包含全体测点排行和当前选中点的趋势及指标，内容较多时按 A4 横向分页。详细公式与适用条件见 [公司测点统计口径](公司测点统计口径.md)。

测点分析要求检测列表完整、非空且不超过 1000 次。服务器生成绑定当前门户登录会话与公司会话的检测范围快照，有效期 30 分钟；前端按每批 20 次读取全部详情，上游详情请求最多同时 2 个。不会只取列表当前页或用已打开的少量详情推算。失败、取消、过期或不完整时不生成统计；更改并应用条件后重新加载。分析期间自动刷新暂停，结束后恢复。详情可以复用五分钟内的成功缓存，页面和导出保留实际读取时间；冻结检测记录范围不等于公司系统提供了同一时刻的详情事务快照。

本机 `GET /local/vision/mes/analysis` 仅接受服务器返回的 `snapshotId` 与固定批次 `offset`。客户端不能指定门户会话范围或任意记录 ID；退出后未完成的请求不能返回数据。分析批次不使用通用响应缓存，避免失败重试和快照过期检查被缓存跳过。

“一键报告”使用当前已应用条件下的全部选中记录，先统计再分页，不以屏幕当前页代替整体样本。前提是本轮读取完整、记录非空、汇总与记录一致；读取中、失败、未应用新条件或范围不完整时不能生成报告。打开预览后暂停页面自动刷新，报告内容冻结；关闭预览后页面可继续刷新，已下载文件不会变化。

按时间查询的报告采用服务器返回的有效起止时间，包括冻结后的实际结束时间。按数量查询的报告明确标注“最近 N 次、不受日期筛选限制”，另列读取截止时刻和本次记录的实际最早、最晚检测时间，不把后台历史搜索下界当作用户选择的日期范围。报告全部时间使用北京时间。

报告包含检测次数、OK／NG 构成、检测量与适用时的合格率趋势，以及物料和检具覆盖。同一物料按“物料编号＋SN 生产线号”分别汇总，无法识别的线号单列“待确认”；MES 检测线体与 SN 生产线号分别标注。自动趋势粒度与页面一致：按实际样本跨度，不超过 1 天用 15 分钟、不超过 7 天用 1 小时，否则按天；手动粒度沿用当前选择。纸面空间不足时合并相邻有记录的分组，合格率使用合并后的 OK 与有效检测次数重新计算，不平均各组百分比，也不填补无记录时段。

限定工件码、只查看 OK／NG、来源判定未知或来源不允许计算整体合格率时，报告隐藏指标、趋势与物料／检具分组中的合格率，仅保留数量与结果构成；构成百分比不是整线合格率。详情测点按需读取，列表查询没有获取全部检测的测点明细，因此报告明确说明没有汇总 NG 测点排行，不从少量已打开的详情推算。来源未提供全检标识、复测分别计次、读取完整不保证现场上传完整等限制随报告保留。

预览可选择“打印 / 另存 PDF”或“下载 HTML”。打印使用 A4 横向并关闭浏览器页眉页脚；HTML 包含报告样式，可独立打开。超出一页时在限定范围内缩放，无法保持可读性时停用导出并提示缩小范围。报告仅是本轮成功查询的快照，不代表公司所有历史记录或现场全部检测已经上传。
