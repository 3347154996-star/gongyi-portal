# 公司测点统计口径

本功能分析当前查询选中的 MES 检测记录及其全部测点详情。每个检测记录 ID 分别计次，同一 SN 的复测不合并。详情没有全部读完、空详情或来源列表不完整时，不能把部分测点当作完整 NG 排行，也不提供 Pp/Ppk。完整读取只描述当前接口范围，不证明现场全部检测已经上传。

## 分组与数据保留

同组必须具有一致的检测线体／工序、物料编号、SN 生产线号、检具编号、测点 key、上下规格限、等值判定方式及单位。名称仅用于展示，不能代替稳定标识。不同物料、检具、线号或规格不合并计算能力。基础测点出现规格或单位变化时各版本分别展示，并停用该点各版本的 Pp/Ppk 和控制界限，提示先确认规格变化。

数值缺失、非数值及无穷大保留为空，不补 0。原始实际值和来源 OK／NG 判定分别保留；未知判定不改成 OK 或 NG。来源未提供单位时不自动写毫米，也不自动将实际值解释成尺寸偏差。未提供关键点标记时不能从名称、NG 判定或测点顺序推断关键性；默认包含所有返回的测点，界面不能假装已区分关键／非关键。

## NG 排行与结果构成

- 每组 NG 次数是来源明确判为 NG 的测点事件数；分母 `validObserved` 是该组来源明确判为 OK 或 NG 的事件数。数值是否有效与来源判定是否明确分别计数，表中同时展示 `NG / validObserved` 和该比例。
- 帕累托累计百分比为“当前排序位置及之前的 NG 测点次数之和 ÷ 全部组的 NG 测点次数”。截取 Top N 后不会把最后一项强制改成 100%，另列剩余 NG 次数。无 NG 时不生成虚构的累计曲线。
- 饼图采用检测列表的整件原始 OK／NG／未知次数。一个不合格检测可能有多个 NG 测点，因此饼图与测点排行的分母不同。

## 数值描述与 Pp/Ppk

`n` 仅计有限数值；Avg、Max、Min、Range 分别为均值、最大值、最小值和最大值减最小值。Std 使用样本标准差 `s = sqrt(Σ(x−mean)² / (n−1))`，最少需要两个有效数值；单个样本的 Std 留空。样本标准差和极差定义依据 [NIST Measures of Scale](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm)。

本功能使用同一组全部有效数值的总体样本波动估算：

```text
Pp  = (USL − LSL) / (6 × s)
Ppk = min((USL − mean) / (3 × s), (mean − LSL) / (3 × s))
```

这里的 `s` 是整个所选组的样本标准差，不是组内波动或移动极差估计值。Pp／Ppk 的总体波动命名参考 [Minitab 官方整体能力公式](https://support.minitab.com/en-us/minitab/help-and-how-to/quality-and-process-improvement/capability-analysis/how-to/capability-analysis/normal-capability-analysis-for-multiple-variables/methods-and-formulas/overall-capability/)。Ppk 可以为负数，不能截为 0；样本零波动时不输出无穷大或“能力优良”。

本模块将 30 个有效数值作为显示下限：少于 30 不提供 Pp／Ppk，30–49 另提示样本偏少。这个门槛是产品保护规则，不是能力认可标准。NIST 的能力说明要求稳定过程与分布假设，提示通常需约 50 个独立数据值，正式能力研究一般需要至少 100 个；参见 [NIST Process Capability](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)。本功能没有证明稳定性、正态性或独立性，因此满足样本门槛的结果仍只标为估算，不输出能力等级或预测不良率。

以下情况不提供 Pp/Ppk：详情未完整、限定单个工件码或 OK／NG 结论造成选择偏差、组身份不明、规格变化、等值判定、单侧／缺失／无效规格、有效数值不足、缺失测点／数值、未知判定、零波动或数值溢出。单侧能力可以有其他指标定义，但本模块不把它们冒充双侧 Pp／Ppk。

## 估计控制界限

对顺序明确的连续数值，采用单值 I-MR 方法：

```text
MRi = abs(xi − xi−1)
UCL = mean + 3 × mean(MR) / 1.128
LCL = mean − 3 × mean(MR) / 1.128
```

公式及 `1.128` 常数依据 [NIST Individuals Control Charts](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm)。图中必须标为“估计控制界限（I-MR），不是规格限”，不能当作公司来源给出的 UCL／LCL，也不照抄截图数值。USL／LSL 始终采用该组实际规格。

按实际检测时间排序；同时间记录用 ID 稳定排序只为显示，不假装已知生产先后。移动极差只用两条相邻、数值有效且各自时间不重复的记录，不跨缺失点、规格变化或同时间顺序不明的记录。没有有效相邻对、移动极差为零、规格变化、等值判定、身份不明、条件截取或详情不完整时不显示控制界限。少于 30 个数值的可计算控制线仅供探索，不作为正式控制基线。

时间轴和 SN 轴使用同一批按检测时间排序的测点事件；SN 轴不会将重复 SN 合并。图表中的空值保持断点。上述控制线与能力估计使用当前样本，仍需现场确认测量系统、抽样方式、过程稳定性和分布后才能用于正式过程评价。

## 验证边界

合成测试覆盖样本标准差、Pp/Ppk 公式及负值、样本数量门槛、零波动、单侧／等值／变化规格、缺失与未知、独立分组、帕累托累计分母、复测计次和不完整详情保护。I-MR 数值使用 NIST 公布的示例核对。测试验证计算规则，不代替现场数据完整性、测量系统分析或过程能力认可。
