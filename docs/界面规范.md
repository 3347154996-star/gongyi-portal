# 门户界面与交互规范

本规范用于后续模块保持统一体验。适用前提是继续使用现有原生 HTML/CSS/JavaScript 门户；业务权限、统计口径和来源完整性仍以各模块契约为准。

## 视觉基础

统一主色 `#2456a6`，正文 `#1d2b43`，次要文字 `#64748b`，边框 `#dce3ed`，页面背景 `#f4f6fa`。常规面板圆角 12px，输入框和主操作高度 40px；正文以 14px 为基准，页面标题 26px、分区标题 17–18px。桌面采用固定导航和限宽内容区，小屏使用折叠菜单和单列布局。公共样式在 `public/portal-theme.css`，工具共享样式在 `public/tools/shared.css`。

主色表示导航和主要操作；红色表示错误/待响应，紫色表示处理中，橙色表示待处理风险/待复线，绿色表示成功。状态必须同时有文字，不能只依赖颜色。图表中的同一 OP 使用稳定的颜色映射，不能按当次排行重新着色。

## 页面与反馈

每页按“页面说明 → 筛选 → 当前状态 → 结果”组织。来源与完整性提示紧凑展示，但不可隐藏影响判断的限制。补焊报表以概览为起点，提供分析和原始记录直达按钮；详细图表、数据表与口径说明通过可展开区域保留。

输入日期、关键词等筛选条件时显示待应用状态。用户提交查询才更新结果；后台刷新使用已应用条件。状态轮询不得重建业务表格，数据刷新需要保留滚动位置和正在查看的区域。查询条件仅按门户账号存储在当前浏览器标签会话中，退出清除，不能保存业务结果或凭据。

备件列表分页，选中后立即显示核对与操作区。不可用的业务动作明确禁用并解释原因。库存变化后保留输入，但要求重新核对；刷新失败不能继续依据旧库存提交。检具时间有明确时区时转换为本地显示，来源未声明时区时保留原文。

## 工具扩展

工具中心通过注册表提供入口，两项工具使用同源独立页面；文件在当前浏览器页处理。新增工具应提供标题、输入输出格式、适用前提、版本和错误反馈。未来远端适配预留接口的细节见 [工具扩展接口](工具扩展接口.md)，未接通的功能不模拟成功。

## 验证边界

变更需要在宽屏与小屏检查主流程、键盘可操作性、空态和错误态。涉及统计、权限和数据导出的改动使用合成数据验证。自动测试不能代替现场数据对账；新设备、真实库存过账与新报表格式仍需单独验收。
